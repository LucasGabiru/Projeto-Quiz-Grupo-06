# Projeto-Quiz-Grupo-06

## Descrição do Projeto
Uma aplicação interativa de Quiz desenvolvida pelo Grupo 06.

## Funcionalidades
* **Interface Dinâmica:** Interface responsiva construída com HTML5 e CSS3.
* **Base de Dados de Perguntas:** Gestão e manipulação de perguntas em formato JSON.
* **Automação/Backend:** Script em Python para processamento de dados do quiz.

## Estrutura de Ficheiros
* `index.html`: Estrutura principal da página web do quiz.
* `style.css`: Estilização e layout visual do projeto.
* `perguntas.json`: Base de dados local com as perguntas, alternativas e respostas corretas.
* `main.py`: Código em Python para manipulação ou suporte do quiz.
* `README.md`: Documentação do projeto.

## Como Executar
1. Certifique-se de ter o ambiente configurado para correr scripts Python (para o `main.py`).
2. Abra o ficheiro `index.html` num navegador web para visualizar a interface da aplicação.
